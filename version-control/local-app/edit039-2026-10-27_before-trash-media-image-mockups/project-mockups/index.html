Portfolio Jockey v2: local app mockups

A fully local, encrypted project tracker for Linux and Android. Every page shows each screen in a desktop window and a phone frame. Use the toggles at the top of each page to switch light/dark or show one layout.

Tags

Manage a project's tags, confirm changes, edit a file's tags.

Preview and editing

Image and video preview, "Edit in another app", the editing banner, save.

Export one project, bulk export, progress, import an encrypted export.
