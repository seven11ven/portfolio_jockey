Export and import

Every export, one project or many, offers two options: lock it with a passphrase you choose, or leave it unlocked as a regular ZIP or TAR. A locked export is a single .pjx file that only Portfolio Jockey can open, with "Import". The vault passphrase is never used for exports.

1. Export a project: unlocked
From the project "…" menu. With the box unchecked, the export is a regular ZIP or TAR that opens anywhere.

6. Export a readable copy of one file
From a file's menu ("Export a readable copy…") or the preview's "…" menu. The file is decrypted straight into the chosen location. Unlike project exports there's no lock option: the point is a normal, readable file to use elsewhere.
