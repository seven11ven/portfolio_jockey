Portfolio Jockey mockups

Static design previews for review before any UI is built. All names and content are fake sample data. Open each file in a browser, and resize the window to see the phone layout.

1. Login
GitHub sign-in, limited to approved accounts. 2. Dashboard
Projects sorted by most recently opened. 3. Project view
Notes and media timeline, with a composer to add more. 4. Upload
Drag-and-drop upload with progress and an error state. 5. Delete confirmation
Type the project name to confirm deletion. 6. Login error
Message shown when a GitHub account isn't on the allowlist. 7. Account menu
Clicking the avatar shows who's signed in and a Sign out option.
