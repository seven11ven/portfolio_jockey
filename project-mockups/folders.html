Folders and the file-explorer view

Folders live inside a project and can sit inside other folders, without a depth limit. A new folder appears right where the files are. The grid stays the default; the list view is a toggle. Search, tag chips and sorting work across the whole project. Folders are only labels inside the project's encrypted index: moving things never rewrites an encrypted file.

1. Project view, grid (the default)
The new toolbar sits under the tag chips: search, sort, grid/list toggle and New folder. Folders come first, then files, like Google Drive. Image files show small in-memory thumbnails; other types keep their badges. The path row shows where you are. Each folder card shows how many files it holds (everything inside it, subfolders included) and its total size.

3. List view (the toggle)
Columns for name, size and date. Click a column heading to sort by it; click again to flip the direction. Folders always stay above files. In the Date column, a file shows the date it was added and a folder shows the date it was created. A folder's size is the total of everything inside it. On a phone the date column is hidden to save room.

5. Search, and tag chips: the whole project
Typing in the search bar (or tapping a tag chip) switches to a flat list of matches from every folder, each with the path it lives in. Clicking a result opens its preview; "Show in folder" in its menu jumps to its folder. Clearing the search returns to the folder you were in. Sorting still applies.

6. Drag a file into a folder
Press and drag a file (or several selected files: the badge shows how many). The folder under the pointer lights up as the drop target. The dragged file fades in place. Folders can be dragged onto other folders the same way, but not onto themselves or anything inside them. Dropping asks for confirmation (scene 8) before anything changes. On a phone, use "Move to…" from the menu instead (scene 11).

8. Confirm a move
Dropping, or choosing "Move to…", always asks first. Nothing about the files themselves changes: they stay encrypted exactly as they are, only the label of where they sit changes. If a name already exists in the target, the moved item is renamed "name (2)".

9. New folder, and rename
"New folder" creates it inside the folder you're in, and it appears straight away among the folders. Rename uses the same dialog. There's no length limit on names. A name can't be empty, can't be "." or "..", and can't contain a slash or control characters. A clashing name is refused with a message (second state).

10. Folder menu (right-click / long-press)
Open, rename, move, export and delete. "Export a readable copy…" exports the folder (and everything in it) as ZIP or TAR through the existing export dialog. Delete is the red item and always asks first (scene 12).

A picker showing every folder in the project, for moving files or folders when dragging isn't convenient, and on a phone. The folder being moved, and everything inside it, is greyed out, so a folder can never end up inside itself.

12. Delete a folder: confirmation
Counts everything inside, subfolders included. The encrypted copies are permanently deleted; the originals on your device are not touched (use "Move to Trash" on individual files for that). The button repeats the number.
