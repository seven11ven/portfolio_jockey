Home and project actions

The project grid, creating a project, and the "…" menu next to each project's name (rename, export, delete).

1. Home
Projects are sorted by most recently opened. On a phone, "New project" is the round + button. The folder button (first icon, "Open vault folder") opens the folder where the encrypted projects are stored in the desktop's file manager; it only holds encrypted files with random names.

6. Inbox button with unread notices
After the app tidies up something left unfinished (for example after a crash or power cut), it adds a notice to the inbox instead of popping up a message. The number shows how many notices haven't been read. With none unread, the icon shows no number.

7. Inbox
Opening the inbox marks its notices as read. Each notice can be dismissed with ✕; "Clear all" dismisses them all. Notices are kept, encrypted in the vault, until dismissed.
