First run and unlock

No account and no login. The passphrase only unlocks the encryption on this device.

1. First run: choose a storage location and set a passphrase
Shown once. Here the passphrase is shown with the eye button, so it can be checked and written down; every passphrase field starts hidden and has its own eye button. A shown passphrase can be copied; "Allow copying passphrases" in Settings turns that off (it's on by default, the user's choice). The checkbox must be ticked before "Create vault" is enabled. Creating the vault writes to disk, and this screen is the confirmation.

1b. First run inside the Flatpak
The installed app runs in a sandbox that can't write to ~/Documents. So the suggested folder is the app's own data folder, which the sandbox may always use. "Change…" opens your desktop's folder picker, which gives the app access to the folder you choose. Everything else is as in scene 1.
