# Portfolio Jockey
A localized, privacy focused application designed to help keep track of projects

## Features
The basic everyday stuff you'd imagine

### Encrypted Projects
Any item uploaded to any Project is automatically encrypted. This is only decrypted when you view it's contents(decrypted locally) or when you edit any item with a third-party application service

### Bulk Exports
Again, bulk exports with password locks(optional) to prevent any random joe from accessing it.

### No Network Dependency
Designed to function 100% offline, no network access required whatsoever.
